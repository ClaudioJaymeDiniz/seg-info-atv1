Repo para entrega dos exercicios de LOG da materia Segurança da Informação:

Exemplo utilizando o linux.
No terminal crie um arquivo exemplo:
----------------
nano exemplo.sh
----------------
cole o script e salve o arquivo, com nano:
ctlr+o > enter > ctrl+x

Criar permissão para o arquivo:
chmod +x nome-do-arquivo.sh

Para rodar :
sudo ./nome-do-arquivo.sh
